今天 AI 行业的主旋律是“效率与规模的再平衡”。一方面，以 GPT-5.5 发布和 Google 对 Anthropic 的巨额投资为代表，模型能力和算力竞赛仍在加速冲向新的高峰。但另一方面，市场开始用脚投票，对成本和体验提出更高要求：Perplexity 转向更经济的自研模型、GPT-5.5 强调编排效率、用户因质量下降而公开批评 Claude，这些都标志着行业正从“不计成本追求性能”的阶段，转向“关注单位经济效益和可持续运营”的成熟阶段。对于决策者而言，这意味着技术选型时，成本效率和用户体验的权重正变得与模型性能同等重要。

🔴 重磅
🔴 Perplexity 部署基于 Qwen 的自研生产模型，大幅优化成本
兼顾准确性与成本，实现帕累托最优
Perplexity 已成功部署一个基于阿里 Qwen 后训练的自研模型，在生产环境中服务日常查询的成本效益已优于 GPT 和 Sonnet 系列。此举是 AI 应用层公司走向垂直整合、优化单位经济效益的关键一步，表明在激烈的市场竞争中，单纯依赖第三方 API 的模式正面临挑战，通过自研或深度定制模型控制成本、提升效率成为构建长期“耐久性”的核心。

🚀 产品
🚀 GPT-5.5 显著提升多智能体编排效率，降低资源消耗
更高的 Token 效率，更低的运行成本
Perplexity 创始人透露，将 GPT-5.5 作为默认编排器（Orchestrator）后，其 AI 系统的计算资源消耗显著降低。这解决了此前多智能体或复杂任务编排器消耗大量 token 的核心痛点，意味着更先进的模型不仅在提升任务解决能力，也在优化作为“系统大脑”的调度效率，这将推动更复杂、更强大的 AI Agent 应用以更低的成本落地。

🚀 DeepSeek 发布 V4 系列模型，性能逼近前沿并支持百万级上下文
